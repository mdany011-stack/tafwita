Demarches 18-07

Liste pour l'editeur de TAFWITA. Ces etapes ne se font pas dans le code : elles se font aupres de l'ANAE, des impots, de l'ANPDP et des hebergeurs. Tant qu'elles ne sont pas terminees, le site ne doit pas afficher « conforme » ni « donnees 100 % en Algerie ».

A ne pas couper : Render et Cloudflare Pages restent en ligne jusqu'a ce qu'un VPS algerien marche. ISSAL n'est pas commande tant qu'ils n'acceptent pas la carte ANAE (ou un RC).

1. Identite (cette semaine)

  • Inscription auto-entrepreneur sur anae.dz : activite Developpeur web (020101) ou Developpeur logiciel (020103).
  • Pas de registre de commerce requis pour ce statut (loi 22-23, art. 9).
  • Dans les 30 jours : NIF aux impots + declaration CASNOS.
  • Completer le paragraphe « Editeur » des mentions avec nom, wilaya, numero ANAE, NIF.
  • Ticket ISSAL : « acceptez-vous la carte ANAE + NIF a la place du RC pour un VPS FleXCompute Ubuntu ? » Ne rien payer tant qu'ils n'ont pas dit oui. Contact : issal.dz/contact, +213 780 806 011.
  • Prendre un rendez-vous juriste / expert ANPDP (une consultation) pour qualifier les donnees et deposer le dossier.

2. Contrats fournisseurs (DPA)

Telecharger et joindre au dossier ANPDP, sans coller de cles API :

  • Render : render.com/dpa et politique
  • Cloudflare : DPA client et politique
  • Brevo : conditions et politique (DPA dans l'espace client Brevo)

3. Dossier ANPDP

Site : anpdp.dz. Guide : obligations du responsable.

Utiliser le modele de dossier (deux traitements + demande de transfert). Joindre : carte ANAE, NIF, politique, CGU, acte de sous-traitance, DPA fournisseurs.

Sans recipisse ANPDP : ne pas ecrire « conforme 18-07 » sur le site.

4. Hebergement algerien (plus tard, pas bloquant)

Seulement si ANAE (ou RC) est accepte par ISSAL ou ICOSNET :

  • 1 VPS Ubuntu (FleXCompute ECO ou equivalent), pas un pack WordPress.
  • Domaine : .com si pas de RC ; .dz souvent exige un RC (nic.dz).
  • Boite mail professionnelle du meme hebergeur a la place de Brevo (SMTP).
  • Pointer le domaine vers le VPS, copier l'API + les HTML, renseigner DATABASE_URL et SMTP sans les mettre dans le code.
  • Mettre a jour le dossier ANPDP (changement de sous-traitants) et les mentions.

Cela reduit le transfert etranger. Cela ne remplace pas les etapes 1 a 3.
