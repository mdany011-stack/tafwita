Traitement A — Comptes cabinets (TAFWITA responsable)

  • Finalite : creer et gerer l'essai / l'abonnement, repondre au contact.
  • Base : execution de mesures precontractuelles et du contrat d'essai ; information de la personne.
  • Donnees : nom, prenom, nom du cabinet, telephone, e-mail, specialite, wilaya, mot de passe hache, IP (limiteur).
  • Personnes : medecins / secretaires qui s'inscrivent ; visiteurs du formulaire contact.
  • Duree : essai 45 jours + abonnement ; traces admin 12 mois ; suppression sur demande.
  • Destinataires : editeur TAFWITA ; Render (hebergement) ; Brevo (e-mail) ; Google (boite contact).

Traitement B — File patients (cabinet responsable, TAFWITA sous-traitant)

  • Finalite : numeroter et appeler les patients du jour.
  • Donnees : nom, telephone optionnel, numero de ticket, evenements de file (libelles generiques).
  • Pas un dossier medical. Qualification exacte (sensible ou non) a confirmer par le juriste.
  • Duree : noms/telephones en memoire jusqu'a cloture de la journee. Numeros sans nom : historique cabinet.
  • Destinataires : le cabinet (console authentifiee) ; TAFWITA (sous-traitant) ; Render (serveur). Cloudflare sert les pages, pas la base des noms.

Demande de transfert hors d'Algerie

En application des articles 44 et suivants de la loi 18-07 (et des dispositions ajoutees par la loi 25-11), demande d'autorisation de transfert vers :

  • Etats-Unis — Render (API, base) ; Cloudflare (pages) ; Google (e-mail de contact).
  • Union europeenne — Brevo (e-mail d'inscription cabinet).

Mesures : HTTPS, mot de passe hache, noms patients hors SQL et hors ecrans publics, DPA fournisseurs, information et case d'acceptation, purge journaliere des noms.
